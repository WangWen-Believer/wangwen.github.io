问题定义：园区 / 地库导航依赖自建图构建导航信息，传统规则 text prompt 对空间拓扑表达能力不足，且受规则噪声影响大，需要建立面向 VLA 训练的园区导航数据最直接的视觉表达标准。

  • 主导园区导航从底图生产到上车验证的全链路设计，贯通导航数据、vision prompt、VLA 后训练与问题闭环。
  • 在 Foundation Model 基础上设计园区 VLA Vision 导航子系统，与行车业务线对齐并共用 vision prompt 接口规范。
  • 主导 vision prompt A/B 实验，相较 text prompt 基线降低转弯选路场景接管率，提升路线完成率。
  • 参与 SFT 合训实验，建立“问题上报 - 分析 - 修复 - 数据补齐 - 复训验证”的模型迭代链路。

关键结果：完成方案验证并进入 OTA 发布准备阶段；vision prompt 表达标准已与行车业务线对齐，可向后续 VLA 场景复用。

  • 负责 EXNGP 多趟增量闭环优化，推动行业首个车端纯视觉增量建图产品于 2025.08 大规模量产部署。
  • 设计并开发 EXNGP MapChecker 车端路网准入防线，异常路网拦截率 >99.9%。

关键结果：相较 Mask2Former 基线识别准确率提升 10%；完成首批标注数据交付，支撑闭环仿真与机器人 VLN 训练需求。

问题定义：泊车场景低速、长时序、多轮换向、局部遮挡和空间拓扑复杂，需要验证 VLA 在 APA 场景中的可行性，并为园区 VLA2.0 建立技术基础。

  • 从 0 到 1 搭建公司首条端到端 APA VLA 预研链路，覆盖数据、AFT、SFT、RL、开环仿真与闭环仿真。
  • 识别图像滑动窗口上下文过短导致长程规划失败的问题，提出历史轨迹 Token 作为压缩式长时序记忆表征。
  • 主导 Trajectory Action Head 在速度、加速度、加加速度、曲率等高阶量上的系统性消融实验，量化各监督项贡献。
  • 设计泊车场景 COT 标注与数据生产方案，提升模型对换向决策、障碍物绕行和局部拓扑变化的表达能力。

关键结果：完成泊车场景 VLA 可行性验证，沉淀视觉表达、后训练数据与仿真验证链路，为园区 VLA2.0 奠定基础。

城区 NOA 在线地图构建 ｜ 毫末智行 2023.07 - 2024.07

问题定义：城区 NOA 需要在常规道路、交换区、路口、汇入汇出等复杂场景中实时构建安全、可达、平滑且时序稳定的引导线。

  • 设计并开发三次多项式与五段式两套参考线算法，覆盖直行、交换区、汇入汇出、路口转向与掉头等场景。
  • 通过五段式参考线方案实现转向场景下曲率连续、曲率可控的引导线生成，降低规划控制侧轨迹突变风险。

关键结果：Logsim 闭环评测中，引导线通过率由 80%+ 提升至 99%+，路口整体通过率由 70% 提升至 80%+。
